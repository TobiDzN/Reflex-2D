# Reflex – 2D Skill Based Shooter

## Overview

Reflex is a fast paced 2D shooter built around timing, precision, and decision making rather than traditional run and gun gameplay.

The idea is simple: both the player and enemies have very limited shots, so every action matters. Instead of spamming bullets, the player has to decide when to attack, when to defend, and when to wait.

---

## Core Mechanics

### One Shot Combat System

The game is built around limited ammunition. Missing a shot puts the player at a disadvantage, so every decision carries weight. Reloading introduces downtime, which forces the player to think ahead instead of reacting blindly.

### Shield and Counter System

The player can activate a shield for a short window to block incoming attacks. If timed correctly, this creates an opportunity to counter. This mechanic encourages a more thoughtful playstyle instead of constant aggression.

### Enemy Behavior

Enemies react to the player instead of following fixed patterns. On higher difficulty, they respond quickly and defend more often, while lower difficulty enemies react slower and make more mistakes. This creates a noticeable difference in how encounters feel.

### Movement and Combat Flow

Movement is responsive and designed to support short, intense encounters. The focus is on quick decisions and clean execution rather than long fights.

---

## What I Learned

Working on this project helped me understand how to design gameplay around limitations instead of adding more features. I learned how to build timing based mechanics, structure enemy behavior to feel reactive, and balance systems so the game feels challenging without being unfair.

---

## Challenges

One of the main challenges was getting the shield timing to feel consistent and skill based. Another was preventing enemies from reacting too perfectly, which made the game feel unfair. Balancing difficulty so that each enemy type felt different without breaking the core system also took several iterations.
